Greenhouse Dataset Generator

Renders random Hikvision PTZ shots inside the simulated Albatha rows and university arches and saves each image with a YOLO label file (0 tomato, 1 cucumber, 2 capsicum, 3 zucchini). A fruit gets a box when enough of it is visible, and the box covers only the visible part. Runs on this computer's graphics card, so leave this tab in front while it works.

Dataset

The same seed and settings give the same dataset again. Change the seed to get new images.

Greenhouses

The university arches grow, flower, ripen and get picked following the production plans, so each new greenhouse gets a random date in this range.

Variety

Each new greenhouse changes plant shapes, leaf density, yellowing, fruit amount and ripeness.

Train with it

The folder ends up as images/train, images/val, labels/train, labels/val, data.yaml, meta.csv (camera settings for every image) and README.txt. With Ultralytics:

yolo detect train data=data.yaml model=yolo11m.pt imgsz=1280 epochs=100
yolo detect train data=data.yaml model=rtdetr-l.pt imgsz=1280 epochs=100

Synthetic images teach shapes, sizes and occlusion, but they don't look exactly like real photos. Mix them with the hand-labelled farm photos and always measure the model on real images only.
